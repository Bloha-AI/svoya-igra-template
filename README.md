# Своя игра

Готовый шаблон учебной викторины на Next.js и React. Учитель открывает табло на своём компьютере, показывает его классу и управляет ответами команд. После сборки получается обычный статический сайт в `out/`.

## Быстрый старт

Требуется Node.js 24 LTS и npm.

```sh
git clone <URL-этого-репозитория> svoya-igra
cd svoya-igra
npm ci
npm run dev
```

Откройте `http://localhost:3000`. Нажмите «Начать игру», задайте названия команд и выберите правила. В демонстрационном наборе «Мир науки» — 25 вопросов для 5–7 классов: космос, природа, Земля, открытия и человек.

## Подготовить другой урок

Отредактируйте **`src/data/game.json`**. Для обычной смены предмета компоненты и игровую логику менять не нужно.

| Поле                            | Что менять                                                              |
| ------------------------------- | ----------------------------------------------------------------------- |
| `id`                            | Уникальный идентификатор нового набора, например `geography-grade-6-v1` |
| `title`, `subtitle`, `audience` | Тема, короткое описание и класс                                         |
| `roundName`                     | Название занятия или раунда                                             |
| `timerSeconds`                  | Время на вопрос от 0 до 300 секунд; 0 отключает таймер                  |
| `defaultTeams`                  | От 2 до 6 названий команд                                               |
| `categories`                    | От 1 до 8 тем, в каждой от 1 до 8 вопросов                              |

Вопрос содержит `id`, `value`, `question`, `answer`, `explanation`. Можно добавить `acceptedAnswers` (массив допустимых вариантов) и `source` (HTTPS-ссылку). Все идентификаторы вопросов уникальны, стоимость внутри темы растёт. Проверка содержимого входит в сборку.

```json
{
  "id": "fractions-100",
  "value": 100,
  "question": "Какая дробь больше: 1/2 или 1/4?",
  "answer": "1/2",
  "explanation": "При одинаковом целом половина больше четверти.",
  "acceptedAnswers": ["Одна вторая", "Половина"]
}
```

Значки темы: `orbit`, `leaf`, `globe`, `lightbulb`, `fingerprint`. Можно указать другое значение — будет нейтральный значок. Палитра и размеры находятся в `src/app/globals.css`. Заголовок страницы и описание автоматически берутся из набора вопросов.

Для каждой новой темы подготовьте все вопросы, ответы и пояснения. Сложность повышайте вместе с ценой, учитывайте возраст учеников и проверяйте факты. Не оставляйте демонстрационные вопросы в чужой теме.

## Возможности

- Синее табло с темами, стоимостью и погашенными клетками.
- 2–6 команд, ручное назначение отвечающей команды и передача права выбора.
- Скрытые ответы и пояснения; ведущий оценивает устный ответ.
- Штраф за ошибку или учебный режим без штрафов; отрицательный счёт.
- Таймер с паузой, сбросом и необязательным звуком. Переключение вкладки ставит его на паузу.
- Защита от повторного начисления и второй попытки той же команды.
- Отмена действий, корректировка счёта, история последних 60 действий.
- Сохранение партии в браузере, восстановление после перезагрузки.
- Итоговая таблица, ничья, досрочное завершение и новая партия.
- Полный экран, клавиатурное управление, адаптация для небольших экранов.

Правильный ответ показывается только по команде ведущего или после завершения розыгрыша. После его раскрытия новые попытки закрыты; оценить можно только команду, выбранную до раскрытия. Истечение времени само по себе не снимает очки и не раскрывает ответ.

`Escape` закрывает окно, сохраняя незавершённый вопрос. `Ctrl/⌘ + Z` отменяет последнее действие (кроме ввода текста). Обычные кнопки работают с `Tab`, `Enter` и `Space`. Все правила доступны внутри игры.

## Сборка и размещение

```sh
npm run check
npm run preview
```

Команда `check` запускает линтер, TypeScript, тесты игровой логики и сборку. `preview` обслуживает **уже собранный** каталог `out/` по `http://127.0.0.1:3000`; предварительно остановите dev-сервер на этом порту или задайте `PORT=3001`.

Для публикации загрузите **всё содержимое `out/`**, включая `_next/`, на статический HTTPS-хостинг. Сервер Node.js на хостинге не нужен. Здесь настроены `output: 'export'` и `trailingSlash: true`; `next start` для такого экспорта не используется. Подойдут хостинги статических сайтов с поддержкой `index.html` в каталогах.

Если сайт размещается в подпапке, задайте её **при сборке** и используйте тот же префикс при предпросмотре:

```sh
NEXT_PUBLIC_BASE_PATH=/quiz npm run build
NEXT_PUBLIC_BASE_PATH=/quiz npm run preview
```

`NEXT_PUBLIC_BASE_PATH` — публичный путь, а не секрет. Для обычного размещения в корне никакие переменные окружения не нужны.

## Устройство шаблона

```text
src/data/game.json                 Содержание урока
src/lib/content.ts                Типы и проверка вопросов
src/lib/game-state.ts              Чистая игровая логика и сохранения
src/lib/use-game.ts                Таймер и локальное сохранение
src/components/game.tsx           Игровое табло и управление ведущего
src/components/question-dialog.tsx Вопрос, ответ и оценка команды
src/components/settings-dialog.tsx Команды и правила
src/components/results.tsx        Итоги
src/app/globals.css                Оформление и адаптивность
tests/game-state.test.ts           Проверки сценариев игры
```

В поддерживающих браузерах дополнительно регистрируются WebMCP-действия чтения табло, открытия вопроса, выбора команды и оценки ответа. Это необязательное улучшение; основной интерфейс от него не зависит. Они используют ту же игровую логику, не делают сетевых запросов и не возвращают скрытые ответы через инструмент чтения.

## Границы базового режима

Это **один раунд на одном устройстве ведущего**. Одна ссылка на разных телефонах открывает отдельные партии. Совместные онлайн-комнаты, кнопки игроков на телефонах, финал со ставками, аукцион и «Кот в мешке» в базовый шаблон не входят.

Сохранения хранятся только в `localStorage` этого браузера. Очистка данных браузера их удаляет. Изменение набора вопросов создаёт отдельную версию сохранения. Одновременная игра в нескольких вкладках одного браузера не синхронизируется; ведите одну партию в одной вкладке.

В шаблоне нет аккаунтов, аналитики, внешних шрифтов, ключей и серверной базы данных. Все вопросы и ответы входят в публичные файлы сайта: скрытие ответа — игровая механика, а не защита информации. Для открытого сайта используйте названия команд без персональных данных учеников.
